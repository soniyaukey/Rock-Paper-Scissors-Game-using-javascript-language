# Rock-Paper-Scissors-Game-using-javascript-language
 🎮 Rock Paper Scissors Game

A fun and interactive Rock-Paper-Scissors game built using HTML, CSS, and JavaScript.
Play against the computer and test your luck!
---------------------

🚀 Features

🎯 Simple and easy-to-play interface

💻 Built using pure JavaScript (no libraries required)

🧠 Randomized computer choices for fairness

🏆 Real-time score updates

🎨 Attractive and responsive UI design
--------------------------------------

🧩 Technologies Used

HTML5 – For the basic structure

CSS3 – For styling and layout

JavaScript (ES6) – For game logic and interactivity
-----------------------------------

⚙️ How to Play

Choose Rock, Paper, or Scissors by clicking the button.

The computer will randomly select one of the three options.

The result will be displayed:

🪨 Rock beats Scissors

📄 Paper beats Rock

✂️ Scissors beats Paper

The score updates after every round.
